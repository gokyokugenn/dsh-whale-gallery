鲸鱼娘主题馆 · DSH 皮肤插件 0.1.3（54 套主题）
2026-11-09

这是一个可安装的 DSH 插件，内含 54 套可即时切换的界面皮肤：自然 13 套、古风 9 套、日式 9 套、海岸 9 套、幻想 6 套、城市 8 套。
每套都是独立配色（11 个颜色 + 圆角 + 装饰母题），按钮、开关、代码块等界面控件会跟着主题走；同时支持深色与浅色界面。
主题馆支持按分类筛选、按关键词搜索，并用「背景浓度」「阅读底色」两个滑块调节插画与正文的关系。
想自己加主题：见 docs/新增主题操作手册.md，画一张 16:9 的 PNG + 填一条配色即可。

桌面版安装
1. 下载并保存 dsh-whale-gallery-0.1.0.tgz，记住文件完整路径。
2. 在 DSH 左侧“插件”中点击“添加插件”，填入这个 tgz 文件的完整路径并安装。
3. 启用“鲸鱼娘主题馆”。新增插件后按 DSH 的提示重启一次应用。
4. 重启后点击侧栏底部“主题馆”，或打开“设置 → 鲸鱼娘主题馆”。点击任意主题即可切换，以后切换无需重启。

CLI Web 版安装
在 PowerShell 中运行（将路径替换成实际下载位置）：
dsh plugin --profile web add 'C:/你的下载路径/dsh-whale-gallery-0.1.0.tgz'
如果正在运行 Web 版，新增插件后按原来的启动方式重启它。profile 名不是 web 时，请改成你实际使用的名称。

使用
- 54 套主题分为自然、古风、日式、海岸、幻想、城市六类，可搜索名称与关键词。
- “明暗配色”可选主题原色、跟随 DSH、浅色、深色。
- “背景浓度”调整插画的显示强度；“阅读底色”调整阅读面板的不透明度。
- “恢复官方外观”立即关闭本插件的皮肤显示，原生 DSH 控件保持可用。
- 当前主题和选项保存在当前浏览器/桌面窗口所使用的站点存储中，不同浏览器或站点之间不自动同步。
- 图片全部随插件本地分发，运行时不需要连接画图服务或外部图片站。

兼容范围与验证
package.json 声明 DSH >=0.2.1-rc.2 <0.2.2-0。验证记录见随附的验证报告。尚未声明支持的未来 DSH 版本，宿主可能自动停用插件；请先适配再使用。
本次使用隔离的空白 profile 进行验证，没有修改用户现有桌面版的插件和设置，也没有重启用户正在运行的 DSH。
其他会改写界面的皮肤插件应在启用本插件时关闭，避免同时覆盖同一界面。若使用参考项目的皮肤管理器，本插件以“鲸鱼娘主题馆”整体出现，54 套主题在本插件面板中切换。

主题
潮汐书房、星海观测、云上航邮、雨夜终端、海月水族馆、雪境极光、青瓷听雨、黄铜航海、樱色磁带、落日巡航、森语温室、深海歌剧、霓虹便利店。

开发
源码包包含 src、themes.json、art-sources.json、assets、scripts 和测试。安装 Node.js 24 或更高版本后运行 npm install、npm run build、npm test。
scripts/build.mjs 从本地背景文件生成内容哈希命名的资源、闭包形式的 DSH 客户端模块和构建记录。npm pack 生成安装包。浏览器端 React/ReactDOM 由 DSH 模块表提供，未重复打包。测试宿主脚本需要独立运行的 DSH 测试实例，其日志保存在上一级工作目录。
