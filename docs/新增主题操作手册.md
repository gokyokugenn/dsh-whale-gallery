# 鲸鱼娘主题馆 · 新增主题操作手册

> 目标读者：想给自己加主题的人。不用懂前端，会跑两条命令就行。
> 一句话流程：**画一张 16:9 的 PNG → 在 `themes.json` 填一组配色 → 在 `art-sources.json` 指向这张图 → `node scripts/build.mjs` → 页面自动热更**。

下文的命令都在**仓库根目录**执行（也就是含 `package.json` 的那一层）。

---

## 一、每套主题要交付什么

| # | 交付物 | 放在哪 | 必需 |
|---|--------|--------|------|
| 1 | 背景插画 PNG | 放哪都行（例如 `art-sources/<主题id>.png`），只要 `art-sources.json` 里指得到 | ✅ |
| 2 | 一组配色（11 个颜色 + 圆角） | `themes.json` 里一条对象 | ✅ |
| 3 | 名称 / 分类 / 关键词 | 同上 | ✅ |
| 4 | 生图用的提示词（档案用，不打包） | 同上，字段名 `newPrompt` | 可选 |

一个「主题」= 1 张图 + 1 条元数据，没有别的文件要改。

> **图放哪**：`assets/` 是**构建产物**（按内容哈希命名，没人引用就自动删），别把它当仓库，也别手改里面的图。
> 本仓库的 `art-sources.json` 直接指向 `assets/` 里已有的哈希图，所以仓库只存一份画；你新加图时放 `art-sources/`（已被 `.gitignore` 忽略）或任何地方都可以，只要在 `art-sources.json` 里指到它。

## 二、图片要求

### 硬性（不满足会出错或明显难看）

| 项目 | 要求 | 原因 |
|------|------|------|
| 格式 | **PNG**（真 PNG，不能是改了后缀的 JPG/WebP） | `build.mjs` 校验 PNG 魔数，不是就报 `Invalid PNG` |
| 比例 | **16:9**（1.778 ± 0.08） | 卡片是 `16/9` + `object-fit: cover`，背景是 `cover`，比例不对直接被裁 |
| 尺寸 | 推荐 **2560×1440**；最低 1920×1080 | 高分屏会按物理像素铺满 |
| 体积 | 单张 **≤ 4 MB** 最好 | 现有 38 张共约 124 MB；它基本等于安装包大小 |
| 色彩 | sRGB，不要 CMYK / 不要带奇怪 ICC | 浏览器色彩管理会偏色 |
| 文字 | **画面里不要出现任何文字、水印、签名、UI 截图** | 会和界面文字打架 |
| 透明 | 不要依赖透明度 | 背景是铺满的，透明区域等于露出纸色 |

### 构图（决定好不好用的关键）

插件把画铺成：`position: fixed; inset: 0; background: <图> right bottom / auto var(--wg-art-scale,100%)`。
意思有三条：

1. **高度永远铺满**（不裁上下）—— 所以背景里看到的构图和主题馆缩略图一致；
2. **右边永远贴住窗口右边**，窗口比图更宽时**裁掉的是左边**（那部分正好落在侧栏底下）；
3. 只有超宽屏（宽高比 ≥ 2.05，比如 21:9）才退回 `cover`，不然左边会露出空带。

再加上正文列固定压在中间，所以每一张都请按这个分区画：

```
0%        20%              50%       62%               80%       100%
|——————————|————————————————|—————————|—————————————————|——————————|
  渐变洗白区     纸面 / 安静区      正文列         鲸鱼娘（脸放这）      尾巴/背景
  （别放内容）  （放低对比的景）  （文字压这）    （脸中心 62%–80%）   （可细节丰富）
```

具体建议：

- **鲸鱼娘放右侧 55%–95%**，脸的横向中心落在 **62%–80%** 之间；头顶留 **≥ 10% 上边距**，尾巴/裙摆可以延伸出画布右下，切掉也没关系。
- **中左（20%–60%）保持「纸面」**：浅色、低对比、大面积安静（窗、墙、雾、水面都行）。正文就压在这里，花不花直接决定读不读得下去。
- **最左 0%–20% 会被渐变洗成纸色**，可以放环境细节，但别放必须看见的东西。
- **底部 18%** 是输入卡 + 状态条的位置（输入卡是纸色卡片），别在那儿放高对比细节。
- **顶部 0%–8%** 是标题条（会话标题、标签页）。
- **不要把人放正中间**——正中一定是正文列。

### 明暗（`tone`）

| 画面 | `tone` | 效果 |
|------|--------|------|
| 白天 / 浅色 / 奶油色 | `light` | 界面用浅色 token，正文深色 |
| 夜景 / 深海 / 霓虹 | `dark` | 界面用深色 token，正文浅色 |

`tone` 声明错了（比如夜景写 `light`），浅色正文会直接压在暗部上糊掉——这是最容易犯也最伤观感的错。

> 另有一条：深色插画在**浅色界面**下会额外加一层纸色遮罩（`skin.css` 里 `data-wg-art-tone='dark'` 那条，88%→72%→透明），所以深色图也能用，只是右侧会淡一些。

## 三、配色字段（`themes.json`）

```json
{
  "id": "celadon",
  "name": "青瓷听雨",
  "group": "自然",
  "tone": "light",
  "accent": "#4e7770",
  "muted": "#69807a",
  "paper": "#f5f2e9",
  "ink": "#233f44",
  "border": "#a7bdb3",
  "surface": "#fbf9f2",
  "darkAccent": "#a3d6c3",
  "motif": "lattice",
  "radius": 6,
  "keywords": "青瓷、新中式、竹影"
}
```

| 字段 | 含义 | 怎么取 |
|------|------|--------|
| `id` | 唯一标识，小写英文 + 连字符 | 自己起，别重复 |
| `name` | 显示名（2–5 字好看） | 场景名 |
| `group` | 分类：**自然 / 古风 / 日式 / 海岸 / 幻想 / 城市** | 主题馆按主题里出现的分类自动生成按钮（这几组排前面，其它值排在后面）|
| `tone` | `light` / `dark` | 见上一节 |
| `paper` | 页面底色 / 遮罩色 | 取画面左侧纸面的主色 |
| `surface` | 卡片、输入框底色 | 比 paper 略亮或略暗一点点 |
| `ink` | 正文色 | 对 paper 要够黑（见对比度） |
| `muted` | 次要文字（时间、说明） | 比 ink 淡一档 |
| `accent` | 强调色（按钮、描边、选中） | 取画面里最醒目的那个同族色 |
| `border` | 描边 | 介于 paper 与 muted 之间 |
| `darkAccent` | DSH 深色模式下的强调色 | 通常把 accent 提亮 |
| `motif` | 装饰母题（影响输入卡描边） | 见下 |
| `radius` | 圆角 px，建议 5–23 | 跟着画面风格走：古风小、都市大 |
| `keywords` | 搜索关键词，用「、」隔开 | 主题馆搜索框匹配它 |
| `artScale` | 可选，取景缩放 50–160，默认 100 = 按窗口高度满幅 | 见下 |
| `artFlip` | 可选，`true` = 整幅左右镜像 | 角色画在左边的图用它，主体会回到右侧 |

**关于 `artScale`（近景图的补救开关）**：默认 100，插画按窗口高度铺满、右下角对齐。如果某张图画成了「胸像/半身特写」，角色在 1853×1005 的窗口里会显得偏大，可以填 `86`–`92` 把它整幅缩小一圈（贴右下角，顶部接缝会被羽化）。代价有两个：①四边会露出一圈 `paper` 底色；②主题馆卡片会跟着缩，变成「画框」样式，与满幅卡片不统一。所以能用中景构图重画时优先重画，不要把 `artScale` 当默认手段。

**有专门装饰的 `motif`**（其余值一律走默认样式）：
`brass`（黄铜双线框）、`gothic`（哥特厚边）、`post`（虚线邮票边）、`snow`（顶部白线）、`lattice`（窗格外描边）、`tech` / `neon`（霓虹细边）、`pixel`（像素硬阴影）。

**宿主控件的颜色**：活动标签、焦点环、主按钮底色、开关、勾选框都自动取主题的 `accent`；实心按钮和开关的底色会按白字对比度自动压深（内部变量 `--wg-accent-solid`），不用你额外配。

### 对比度门槛（自检脚本会算）

| 组合 | 最低 | 理想 |
|------|------|------|
| `ink` 对 `paper` | 4.5:1 | ≥ 7:1 |
| `muted` 对 `paper` | 3:1 | ≥ 4.5:1 |
| `accent` 对 `paper` | 2.2:1 | ≥ 3:1 |
| `surface` 对 `paper` | — | 1.02–1.12:1（差太多会突兀） |

## 四、加一套的具体步骤

```powershell
cd <仓库根目录>
```

**1. 存图**

```
art-sources\<id>.png
```

（放哪都行，只要下面 `art-sources.json` 里的 `path` 指得到。绝对路径也支持。）

**2. 在 `themes.json` 末尾追加一条**（注意数组逗号）

```json
{
  "id": "snow-train",
  "name": "雪国列车",
  "group": "自然",
  "tone": "light",
  "accent": "#4a6b8a",
  "muted": "#6d8296",
  "paper": "#f2f5f8",
  "ink": "#1d3244",
  "border": "#b3c6d4",
  "surface": "#fbfdff",
  "darkAccent": "#a9cdf0",
  "motif": "snow",
  "radius": 12,
  "keywords": "雪、车窗、晨雾"
}
```

**3. 在 `art-sources.json` 末尾追加一条**

```json
{ "id": "snow-train", "path": "art-sources/snow-train.png" }
```

> `themes.json` 里的每个 `id` 都必须在这里有一条，缺一条整个构建就报 `ERR_INVALID_ARG_TYPE ... Received undefined` 直接停下（不会半截打包）。

**4. 自检 + 构建**

```powershell
node .\scripts\check-theme.mjs    # 先体检：0 个错误才继续
node .\scripts\build.mjs          # 输出 {"themes":39,...} —— themes 应该比上次 +1
```

`build.mjs` 会自动做这些，不用手动管：

- 校验 PNG、按内容 sha256 重命名成 `assets/<64位hex>.png`（所以别自己起名）；
- 重新生成 `assets/manifest.json`（路由白名单）、`lib/themes.json`、`lib/client.js`、`build-info.json`；
- 清掉 `assets/` 里没人引用的旧 hash 图。

**5. 让它生效**

分两种情况，**别搞混**：

| 你改了什么 | 怎么生效 |
|---|---|
| **加了新图**（新主题 / 换掉某张图） | **必须完全退出 DSH 再打开**。素材白名单 `assets/manifest.json` 是服务端在插件加载时读进去的，光刷新页面新图会 404（主题馆里就是一张空白卡片） |
| 只改了配色 / CSS / 圆角等 | 刷新页面（Ctrl+R）就行，`dsh-client-hmr` 每 500ms 扫构建产物 |

（桌面端建议从托盘「退出」再启动；只关窗口有时进程还在。）

**6. 主题馆里验一眼**

侧栏底部「主题馆」或 设置 → 鲸鱼娘主题馆 → 新主题应该出现在对应分类里，点一下即时切换。

## 五、交付前自检清单

- [ ] `node scripts/check-theme.mjs` → **0 个错误**
- [ ] `node scripts/build.mjs` → `themes` 数字比上次 +1（现在是 38）
- [ ] 主题馆卡片（16:9 右对齐裁切）**没切到脸**（加新图后要重启 DSH 才有缩略图）
- [ ] 新会话页：输入框居中、标题条正常
- [ ] 对话页：右侧鲸鱼娘清楚，正文压在画上仍然读得清
- [ ] DSH 切到深色模式再看一遍（`darkAccent`、`tone` 是否合适）
- [ ] 主题馆搜关键词能搜到、点分类能筛到

## 六、常见坑

| 症状 | 原因 |
|------|------|
| `Invalid PNG: xxx` | 图不是真 PNG（JPG 改后缀 / 导出成 WebP） |
| `TypeError: The "path" argument must be of type string` | `art-sources.json` 里没加这条 id |
| 下次 build 报文件找不到 | 母图放在 `assets/` 里了：图一改哈希名就变、旧文件被当孤儿删掉。母图留在 `art-sources/` 或仓库外，`assets/` 只当构建产物 |
| 卡片里脸被切掉一半 | 图不是 16:9，或脸放到中间去了 |
| 对话页正文看不清 | `tone` 写反了，或中左区域画得太花 |
| 分类按钮多出一个奇怪的 | `group` 写错了：分类按钮按主题里出现的 `group` 自动生成，同组要写完全一致 |
| 装完还是旧样子 | 没跑 `build.mjs`；或 `node_modules` 里那份没换（`lib/client.js` 用「写临时文件 → 删原件 → 移动」替换，别原地覆盖硬链接） |
| 包越来越大 | 单张图太大；先压到 4 MB 内再问 |

## 七、想省事的话

最省事的方式：**丢一张 PNG + 一句话描述**（比如「雪夜车站，冷蓝，柔光」），让维护者或 AI 助手帮你做完下面几件事：

1. 从图里取色，按上面的对比度门槛把 11 个颜色填好；
2. 生成 `themes.json` / `art-sources.json` 的条目；
3. 跑 `check-theme.mjs` + `build.mjs`；
4. 热更后截图给你确认构图裁切对不对。

想自己填的话，就按第四节的 JSON 模板来，改完跑两条命令即可。
